> **Motto:** *"Free for everyone, forever. No paywalls, no subscriptions."*

## 🚀 Free Deployment Guide

### Deploy to Vercel (100% Free)
1. Push this repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Studyo"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/studyo.app.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository.
4. Framework Preset: **Vite** (Root Directory: `./`).
5. Click **Deploy**. Your site will be live worldwide in ~30 seconds with a free SSL certificate!
